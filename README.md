# Burger Page

Welcome to **Burger Page**! 🍔

This project is a web application designed to create and showcase burger menus in an attractive and functional way. It was developed to demonstrate frontend development skills and provide an interactive experience for burger enthusiasts.

## Features

- Visual catalog of burgers with images and descriptions.
- Modern and responsive interface for all devices.
- Intuitive and fast navigation.
- Cloud deployment for immediate access.

## Technologies Used

- **React** for the user interface.
- **Vercel** for deployment and hosting.
- **CSS** for responsive and appealing design.
